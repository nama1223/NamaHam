## Overview

I tried to create a simple app to replicate a certain company's Harmony Direction... or whatever it's called.

I recommend using it connected to a speaker.

This app only handles the keyboard part; the metronome function is left to "[NamaMetro](/Store/NamaMeto/NamaMetoStore.html)".

With the integrated app "[NamaSound+](/Store/NamaSoundPlus/NamaSoundPlusStore.html)", you can use both simultaneously within a single app.

When combined, it might even be more functional than the original.

### How it works
・Making sound
Tapping the keys produces a sound.
Turning on the "Sustained Sound" button in the upper left corner will sustain the sound with each tap, and stop it with another tap.

・Adjustment function
The [Range] screen displays a keyboard with 4 octaves, and you can adjust it up or down using the range button in the upper right corner.
[Transpose] You can transpose the keyboard using the button in the upper left. Setting it to Bb allows you to play trumpet and clarinet sheet music directly.

[Harmony] and [Just Intonation]
These functions are located at the bottom. In just intonation mode, setting it to automatic detection automatically detects the harmony from the combination of keys played and plays it in just intonation.

You can also manually set the key of the chord; pressing a key after the "Play Root" button allows for quick key selection.

Automatic detection may behave incorrectly with complex chords. (Reports of misrecognition are welcome.)
The lowest note is important for detection, and the formula can only handle it when that note is the root (1st) or the 5th.

### Integrated Version
This app is also included in the integrated app [NamaSound+](/Store/NamaSoundPlus/NamaSoundPlusStore.html), which combines a metronome (NamaMetro) and tuner (NamaTune).
