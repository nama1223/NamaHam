## 概要

某社のハーモニーディレク……なんとかを、アプリで簡易的に再現できないかと作ってみました。
スピーカーに接続しての使用をおすすめします。

このアプリでは鍵盤の部分だけ担当して、メトロノーム機能は「[NamaMeto](/Store/NamaMeto/NamaMetoStore.html)」に任せてあります。
統合アプリ「[NamaSound+](/Store/NamaSoundPlus/NamaSoundPlusStore.html)」なら1つのアプリ内で同時に使えます。
全部合わせると本物より高機能になってしまったような気も。

### しくみ
・音を出す
鍵盤をタップすると音が鳴ります。
左上の「持続音」ボタンをONにすると、タップで伸ばしっぱなしになり、もう一度タップで音が止まります。

・調整機能
［音域］画面には4オクターブ分の鍵盤が表示されていて、右上の音域ボタンで上下にずらす事ができます。
［移調］左上のボタンで鍵盤の移調が出来ます。Bbにすればトランペットやクラリネットの楽譜をそのまま弾けます。

［和声］と［純正律］
下段にある機能です。純正律モードで自動判定に設定すると、弾いた鍵盤の組み合わせから和声を自動判定して純正律で鳴らします。
手動で和音の調を設定する事もでき、「根音を弾く」ボタンの後に鍵盤を押すと素早く調指定が可能です。

自動判定は複雑なコードでは挙動がおかしい場合があります。（誤認識の報告歓迎）
最低音が判定上で重要なので、そこに関しては1度か5度でないと計算式で対応できない気はします。

### 統合版
このアプリは、メトロノーム（NamaMeto）・チューナー（NamaChu）と一緒になった統合アプリ [NamaSound+](/Store/NamaSoundPlus/NamaSoundPlusStore.html) にも収録されています。
